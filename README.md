# S. Abhiram — Futuristic Developer Portfolio

A production-grade personal developer portfolio for **S. Abhiram**, built with Next.js 16 (App Router), React 19, TypeScript, Three.js, and Tailwind CSS.

## 🚀 Key Highlights

- **Interactive 3D Hero Experience:** Real-time computational icosahedral neural lattice powered by Three.js with pointer-tracked parallax, dynamic lighting, and accessible non-WebGL & reduced-motion fallbacks.
- **Featured Auriseg AI Case Study:** In-depth technical breakdown of the multi-agent code review pipeline engineered during the Auriseg AI Development Internship (LangGraph async map-reduce, Google Gemini LLMs, ChromaDB/FAISS vector retrieval).
- **CrisisOS / DisasterPulse TN Project:** Documented evidence-backed flood intelligence architecture featuring the calibrated FloodNow TN v1 ML model (Platt scaling, India Flood Inventory v3), OSM highway network KD-tree snapped routing, and 53 automated verification tests.
- **CourierX Relational DBMS:** Relational database management architecture with MySQL schema normalization, primary and foreign key constraints, debounced parcel tracking, and Python/Flask backend APIs.
- **Categorized Technical Matrix:** Strictly verified skills matrix separating completed production technologies from actively explored tools without artificial percentage bars.
- **Interactive Inspection Modals:** Deep-dive architectural modal inspection for all featured projects with problem statements, engineering contributions, and verified technology badges.
- **Futuristic Dark Aesthetic:** Tailored near-black color scheme (`#05070c`), electric mint-green accents (`#00f59b`), restrained cyan & violet highlights, fine cyber grids, and responsive layouts across desktop, tablet, and mobile.

## 💻 Getting Started Locally

### Prerequisites
- Node.js 18.17+ (Node 20+ recommended)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/abhi-45-dev/portfolio.git

# Navigate into the project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
